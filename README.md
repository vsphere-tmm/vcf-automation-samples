# Sample project creation with java

This repository contains the sample code to create a project [Sample project creation with Project SDK](https://<<vcfa>>/project-service/api/swagger/v3/api-docs/2019-01-15).

## Quickstart

Try out the Sample project creation in this repository.

### Prerequisites

* You will need to provide the following details in application.yaml:
    * `access_token`
    * `server_url`

### Steps

#### 1. Clone this git repository.

```
git clone https://github-vcf.devops.broadcom.net/vcf/vcf-automation-samples
```

#### 2. configuration
```
application.yaml

```

#### 2. Sample project creation code is present in automation package.

```
cd src/main/java/com/vmware/vcfa/samples/automation/ProjectService.java
```
